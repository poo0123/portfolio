## 配色とテーマ

右上のボタンで切り替える。選択内容は `localStorage` に保存する。

**未選択の利用者**に対してのみ、日没前後の判定にもとづいて初期値を決定する。
一度でも手動で切り替えた場合、その設定を上書きしない。

| | 昼 | 夜 |
| --- | --- | --- |
| 背景 | `#f4efe3` | `#070b1c` |
| 文字 | `#2f2823` | `#e3ebff` |
| 背景装飾 | — | 左上に月光、右下に沈んだ雲 |

夜間のみ表示する要素:

- **蛍** — 16個（狭い画面では9個）。16〜30秒周期で移動し、2.6〜5.4秒周期で明滅する。
  位置・大きさ・速度・位相はすべて個別に乱数で決定する
- **雲** — 5枚（狭い画面では3枚）。150〜280秒かけて右から左へ流れる。
  4つの放射グラデーションをずらして重ねた塊で、**中心は月光より暗く、外周は背景より明るい**。
  この一枚で「背景上では雲に見え、月光に重なると影になる」の双方を満たす
- **月光の明滅** — 23秒周期で不透明度が変化する

昼に戻した時点で蛍と雲は破棄する。非表示中に計算資源を消費しない。

## 天気との連動

[Open-Meteo](https://open-meteo.com/) から現在の天気を取得し、背景に反映する。
API キーも登録も不要。画面上に天気を文字で表示することはしない。

| 天気 | 表示 |
| --- | --- |
| 雨 | 雨粒を 70 本描画する |
| 雪 | 雪を 60 粒描画する |
| 曇 | 背景をわずかに暗くする。夜間は雲を濃くする |
| 晴 | 背景をわずかに明るくする。夜間は雲を薄くする |

不定期に画面を横切る装飾（風船・紙飛行機・落ち葉・シャボン玉／夜間は蛾・流れ星）も
天気を参照する。**降雨・降雪時は風船とシャボン玉を抑制し、出現間隔を 1.6 倍に広げる。
雲がある場合は流れ星を表示しない。**

## 余白の装飾

幅 1180px を超える画面では、本文の左右に半券・レシート・写真・付箋を
画面外へはみ出す形で配置し、緩やかに上下させる。

はみ出し量は固定値ではなく `min()` で画面幅から算出する。
広い画面では 85〜90% が可視となり、狭まるにつれて画面外へ退避する。
最小幅の 1180px においても本文との間隔は 34px 以上を確保する。

## Discord 連携

[Lanyard](https://github.com/Phineas/lanyard) の WebSocket（`wss://api.lanyard.rest/socket`）に
接続し、受信した内容をそのまま描画する。認証は不要。

取得・表示する項目:

- オンライン状態（オンライン / 退席中 / 取り込み中 / オフライン）
- アバターおよび**アバターデコレーション**
- **ネームプレート** — 動画版（`asset.webm`）を再生する。
  透過部分を含むため、再生開始を検知した時点で背後の静止画を除去する。
  読み込みに失敗した場合のみ静止画（`static.png`）へ戻す
- **サーバータグ** — 氏名の右側に、Discord 本体と同じ並びで配置する
- アクティビティ（ゲーム / 動画 / 音楽 / 配信 / 参加中）
  - **2件まで**表示し、超過分は「ほかに ◯ こ」として折りたたむ
  - 終了時刻が判明するもの（音楽・動画）は**再生バーと再生位置**を併記する
  - アクティビティの画像は直接参照すると拒否される場合があるため、
    `media.discordapp.net` を経由して取得する

> Lanyard の利用には、Lanyard の Discord サーバーへの参加が必要。

## Discord のリンク埋め込み

`index.html` 内の次のブロックが該当する。

```html
<script id="discord:component-embed" type="application/json">
```

Discord の Components v2 により、見出し・説明・アイコン・画像・ボタンを構成する。

制約:

- コンポーネントは **40 個**まで、全体で **3,000 バイト**まで
- ボタンは 1 行あたり **5 個**まで
- 画像は PNG / GIF / JPEG / WebP / AVIF

バイト数には空白も含まれるため、整形時のインデントが制限に影響する。

X や LINE に投稿した場合は、`og:image` に指定した `photo/ogp.jpg`（1200×630）が使われる。

## 動作とデプロイ

静的ファイルのみで構成されるため、そのまま配信すれば動作する。

```sh
npx serve .
```

Cloudflare へは `main` への push で自動的に反映される（Workers Builds）。
手動で行う場合:

```sh
npx wrangler deploy
```

`.assetsignore` に記載したファイル（`.git` / `README.md` / `wrangler.jsonc` など）は
配信対象から除外される。

## アクセシビリティ

OS 側で視差効果の低減（`prefers-reduced-motion`）を有効にしている場合、
蛍・雲・雨・雪・余白の装飾の揺れ・画面を横切る装飾をすべて抑制する。
配色と内容は変更しない。
